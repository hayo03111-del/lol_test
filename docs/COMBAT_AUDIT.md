# 전투 엔진 감사 (94차)

94차에서 전투 엔진 전체(시전·평타·적중·투사체·상태 효과·보호막·미니언·포탑·구조물·초기화·시간·성능)를 다시 읽고 고친 기록이다.
엔진을 새로 쓰지 않았고 기존 공용 경로만 고쳤다. 챔피언별 피해 공식은 추가하지 않았고, 근거 없는 수치 변경도 하지 않았다.

## 상태 표기

| 표기 | 뜻 |
|---|---|
| 완료 및 검증 | 고쳤고, Node 단위 테스트 또는 브라우저 점검으로 동작을 확인했다 |
| 수정 완료, 검증 미완료 | 고쳤지만 그 동작을 직접 재현하는 자동 점검은 아직 없다(기존 회귀 점검은 통과) |
| 미완료 | 확인했지만 이번 차수에 고치지 않았다(이유 적음) |
| 외부 검증 필요 | 원작(26.x) 수치·규칙 확인이 필요해 손대지 않았다 |

결함 분류: 기능 오류 / 특정 상황 오류 / 전투 규칙 불일치 / 상태·타이머 잔류 / 성능·자원 / 미구현 / 테스트 부재.

## 7. 시간·상태 안정성

- 시계는 셋이다: 프레임 dt, `performance.now()`(약 290곳), `setTimeout`. 이번 차수에 게임 규칙 시계(웨이브·포탑·유물·미니언 AI)를 프레임 dt 누적으로 옮겼다.
- 95차: 상태 효과·재사용 대기·스킬 타이머도 일시정지 중에는 멈춘다(완료 및 검증 - `enemy_bot95_test`, `qa_enemy_bot`).
- 96차: 고정 간격 시뮬레이션 - 긴 프레임은 0.05초 조각으로 최대 3번 나눠 돌린다(예전엔 잘라서 13fps면 65% 속도). 0.15초를 넘는 멈춤만 버리고 게임 시계에서도 뺀다.
  페이지 전체 `performance.now()`·`setTimeout`·`setInterval`이 게임 시계라 번들·three.js·점검 스크립트가 같은 시계를 본다(완료 및 검증 - `enemy_bot95_test`, 회귀).
- 사망 후에도 남는 챔피언 타이머(이미 시전된 지연 효과)는 원작처럼 터지는 것이 맞는 경우가 많아 일괄 정리하지 않았다(미완료, 개별 확인 필요).

## 8. 관찰 도구

- F9 디버그 패널에 `--- combat ---` 절 추가: 선입력 대기 스킬과 경과 시간, 보류된 소환사 주문, 걸린 상태 효과, 보호막, 최근 전투 기록 8줄.
