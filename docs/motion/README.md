# 스킬 모션·판정 타이밍 비교 (17챔피언 × Q/W/E/R)

결과 파일: [`motion_timing.csv`](motion_timing.csv) / [`motion_timing.json`](motion_timing.json) (68행, 7차 수정 후 재측정 값)

각 행에는 다음이 들어 있습니다: 영상 출처 URL·상태·실패 사유, GLB 클립명·길이·재생 순서, PC 위키 시전 시간(출처·상태), 게임 측정값(최초 시각 효과, 투사체 생성, 최초 피해, 행동 잠금 해제), 위키 대비 오차, 측정 조건, 신뢰도, 플래그, 코드 조사 메모.
지표는 서로 다른 것으로 취급합니다: **위키 시전 시간 / 클립(모션) 길이 / 행동 잠금 해제 / 투사체 생성 / 최초 피해**. 확인하지 않은 값은 비워 두었습니다(실측값으로 표시하지 않음).

## 1. 영상 확보 결과: 실패(네트워크 정책)
- 공식 스킬 미리보기 영상은 PC 위키에 `[챔피언]_[스킬]Video.ogv/webm` 규칙으로 올라와 있습니다. 검색으로 파일 페이지까지 확인된 것은 20개(가렌 Q/E/R, 다리우스 E, 마스터 이 R, 야스오 R, 모데카이저 E, 레넥톤 Q/W/E/R, 초가스 Q/W/R, 이즈리얼 Q, 애쉬 Q/W/E/R, 아리 Q)이고, 나머지 48개는 카테고리 페이지만 기록했습니다([`video_sources.json`](video_sources.json)).
- 이 실행 환경의 네트워크 정책이 wiki.leagueoflegends.com, static.wikia.nocookie.net, YouTube, Riot CDN(cloudfront), archive.org, Wikimedia를 모두 차단합니다(curl 응답 000). 우회 접속은 하지 않았습니다. GitHub 공개 저장소에서 대체 사본도 찾지 못했습니다.
- **8차 진단(2026-10-12)**: 차단 주체는 대상 서버가 아니라 세션의 egress 프록시입니다.
  - `curl -v https://wiki.leagueoflegends.com/en-us/api.php?action=query&meta=siteinfo&format=json` → 로컬 프록시(127.0.0.1)에 보낸 `CONNECT wiki.leagueoflegends.com:443`이 `HTTP/1.1 403 Forbidden`으로 거부됐습니다(http_code 000, connect_code 403). TLS 연결도 위키 서버의 HTTP 응답도 없었습니다.
  - 403 응답 본문: `request blocked: no rule or allowlist entry allows host "wiki.leagueoflegends.com"`. leagueoflegends.com, static.wikia.nocookie.net, www.youtube.com도 같은 문구였고, 같은 프록시로 github.com은 `200 Connection Established`였습니다.
  - 프록시 상태(`$HTTPS_PROXY/__agentproxy/status`)에는 `connect_rejected: gateway answered 403 to CONNECT`가 기록됐습니다.
  - Python urllib도 `Tunnel connection failed: 403 Forbidden`으로 같은 결과였습니다. 따라서 브라우저(크롬북) 문제나 위키 측 거부가 아니라, 이 세션의 허용 목록에 호스트가 없는 상태입니다. 네트워크 설정은 세션 시작 시 적용되므로 설정을 바꾼 뒤 새 세션에서 다시 실행해야 합니다.
  - `fetch_wiki_videos.py` 실행 결과: 17개 챔피언 모두 카테고리 조회 단계에서 같은 사유로 실패했습니다(68개 스킬 전부 미확보). 실패 사유는 "프록시 CONNECT 거부"와 "대상 서버 HTTP 응답"을 구분해 `video_sources.json`에 기록하도록 고쳤습니다.
  - 대체 경로: GitHub 코드·저장소 검색은 이 세션이 지정 저장소 밖 API를 쓸 수 없어 403이었습니다. WebFetch는 호스트를 해석하지 못했습니다(ENOTFOUND). WebSearch(위키 도메인 한정)로는 파일 이름 일부만 추가로 확인했고 영상 자체는 얻을 수 없었습니다. 결과는 `video_sources.json`의 `searchNote`에 낮은 신뢰도로 기록했습니다(예: 리 신 Q/E/R은 챔피언 문서에 "No video available" 표시).
- 따라서 **공식 영상 프레임과의 비교는 아직 0건**입니다. `videoMotionOnsetSec` 칸은 전부 비어 있습니다.
- 해결 방법: 클라우드 환경 설정(세션 제목 표시줄의 환경 메뉴 → Edit → Network access)에서 `wiki.leagueoflegends.com`을 허용하면 됩니다(위키 API와 미디어 파일이 같은 호스트). 또는 영상 파일을 직접 업로드해도 됩니다.
- 허용되면 `tools/motion/fetch_wiki_videos.py`를 돌립니다. MediaWiki API로 카테고리의 실제 파일명을 확정한 뒤 내려받고, `video_events.py` 분석 결과를 `video_events_<챔피언>_<스킬>.json`으로 저장하면서 `video_sources.json`의 상태를 갱신합니다. 이어서 `build_report.py`를 다시 돌리면 비교표의 `videoMotionOnsetSec`가 채워집니다.

## 3. 측정 방법
- **GLB 클립**: `tools/motion/glb_clips.py`로 17개 GLB의 773개 클립 이름·길이를 파싱했습니다([`glb_clips.json`](glb_clips.json)). 스킬과 클립의 대응은 게임이 실제로 재생한 클립(측정 중 기록)으로 정했습니다.
- **게임 판정**: `tools/motion/measure_events.js`(16ms 폴링: 최초 피해·투사체·시각 효과)와 `measure_clips_unlock.js`(8ms 폴링: 재생 클립·잠금 해제)로 측정했습니다. 기존 E2E 서버를 재사용했습니다.
  - 해상도 240×135, 약 46fps에서 측정했습니다. 게임 시간이 실제 시간의 1.016배로 흘렀습니다.
  - 1280×720에서는 9fps가 나오고, 게임 루프의 프레임당 0.05초 제한 때문에 게임 시간이 실제의 0.45배로 흘러 측정값이 왜곡됩니다.
  - 오차는 약 ±(프레임 22ms + 폴링 간격)입니다. 측정 대상은 150 유닛 앞의 허수아비이고, 투사체 스킬은 이동 시간이 포함됩니다.
- **영상 분석기**: `tools/motion/video_events.py`. OpenCV로 프레임별 움직임 에너지와 밝은 픽셀(HSV V≥230) 면적을 계산해 시전 시작·모션 피크·이펙트 출현 시점을 추출합니다. 컨테이너 타임스탬프와 fps를 그대로 보존합니다.
- **분석기 검증**: 공식 영상 대신 우리 게임 화면을 녹화해서 검증했습니다(`record_validation.js`, 480×270·25fps, 1프레임 40ms). 시전 직전에 하얀 동기화 표식을 띄우고, 게임 내부 이벤트 시각과 비교했습니다([`validation_*.json`](.)).

| 녹화 | 이펙트 출현 − 실제 피해 | 시전 시작 검출 − 실제 시전 |
|---|---|---|
| 이즈리얼 Q | −15ms(시각 효과 기준) | +115~155ms |
| 다리우스 R | +39ms | +63ms |
| 세트 W | +41ms | +205ms |
| 애쉬 W | +70ms | −98ms |
| 가렌 R | +151ms | 검출 실패(대기 동작과 구분 안 됨) |
| 초가스 Q | +323ms | 검출 실패 |

정리하면, 이펙트 기준 피해 시점 추정은 6건 중 4건이 ±70ms 이내였습니다. 시전 시작 검출은 6건 중 2건이 실패했습니다. 저해상도 녹화에서는 챔피언이 작아 신호가 약합니다. 공식 영상(720p)이나 ROI 지정(`--roi`) 시에는 다시 평가해야 합니다.
처음 녹화 2번은 UI 패널이 화면을 가리거나 동기화 표식이 숨겨져 무효였고, 결과에서 제외했습니다.

## 4. 수정 후 재측정 결과(7차 수정 반영)
첫 측정에서 플래그 23건이 나왔고, 수정 후 재측정하니 10건으로 줄었습니다. 이번에 고친 것:
- 시전 시간 반영: 리 신 Q/E, 이즈리얼 Q/W/E, 아리 Q/E, 벡스 R, 초가스 R은 시전 즉시 판정하던 것을 0.25초 뒤로 옮겼습니다. 초가스 Q/W는 0.25초에서 0.5초로, 애쉬 R은 0.5초에서 0.25초로 고쳤습니다.
- 닐라 Q: 클립 3개가 다 끝난 뒤(1.14초) 판정하던 것을 시전 시간 0.35~0.28초에 판정하도록 바꿨습니다. 남은 모션은 언제든 끊을 수 있습니다.
- 레넥톤 Q: 약 0.5초 뒤 판정하던 것을 즉시 판정 + 0.25초 평타 금지로 바꿨습니다.
- 초가스 W: 판정 방향을 캐릭터가 바라보는 방향에서 조준 방향으로 바꿨습니다.
- 행동 잠금: 아리 E(2.9초 → 0.35초)와 요네 W(판정 뒤 1.5초 → 즉시)를 줄였습니다.
- 벡스 Q/W/E를 전용 구현했습니다. Q는 가속 파동(관통), W는 보호막과 반경 피해, E는 지정 지점 폭발과 둔화입니다. 패시브(파멸과 우울)는 아직 미구현입니다.
- 벡스 R: GLB에 없는 `Spell4` 클립을 찾고 있어 모션이 재생되지 않았는데, 실제 클립 `Spell4_Cast`/`Spell4_Dash`로 고쳤습니다.
- 이즈리얼 R 투사체 속도를 5000에서 2000(PC 위키)으로 고쳤습니다.

**측정 오차 참고**: setTimeout으로 처리되는 판정은 헤드리스 소프트웨어 렌더링(swiftshader)의 메인 스레드 부하 때문에 타이머마다 약 50~100ms 늦게 실행됐습니다. 예를 들어 리 신 Q는 0.25초 시전 + 투사체 0.08초인데 측정값은 0.52초였습니다. 프레임 dt로 처리되는 판정(애쉬 W 측정 +19ms)은 오차가 작습니다. 실제 브라우저(GPU, 60fps)에서는 이 지연이 훨씬 작을 것으로 예상하지만, 직접 확인하지는 않았습니다.

## 4-1. 8차: 남은 잠금 플래그 확인(브라우저 상태 추적)
`getActionAuthority()`와 액션 단계를 8ms마다 기록해 확인했습니다(240×135, swiftshader).
- **가렌 Q / 다리우스 W (버그, 수정함)**: 강화 평타 오버라이드의 액션 데이터에 `cancelToMove`/`cancelToSpell`이 빠져 있었습니다. 그래서 적중 후 후딜 내내 `canMove:false`였습니다. 후딜은 공격속도 기준이라 가렌 기본 공속에서 약 1.2초였고, 그동안 이동 명령이 대기열에만 쌓였습니다. 일반 평타와 같게 취소를 허용했습니다(`controller_combat.js`). 수정 후 후딜 시작(가렌 450ms, 다리우스 382ms)에 이동 명령을 내리면 즉시 MOVE로 바뀌는 것을 확인했습니다. 표의 잠금 해제값은 입력 없이 둔 경우라 바뀌지 않습니다.
- **닐라 R (정상, 측정 조건 영향)**: 채널 내내 `canMove:true`이고 평타·스킬만 막힙니다. 코드상 끝나는 시각은 선딜 0.16초 + 채널 1.0초 + 종료 후 0.12~0.32초입니다. 측정 2.2초는 그 실행에서 17fps가 나와 프레임당 dt 0.05초 제한으로 채널(게임 시간 1.0초)이 실제 약 1.75초 걸렸기 때문입니다. 종료 후 0.32초 잠금은 원작 근거를 확인하지 못했습니다.
- **모데카이저 R (정상으로 판단)**: 코드상 잠금은 시전 0.5초(위키) + 엔진 여유 0.15초 = 0.65초입니다. 측정 0.97초와의 차이는 setTimeout 지연으로 봅니다. 실제 GPU 브라우저에서는 확인하지 않았습니다.

## 4-2. 9차: 원작(PC 위키) 고증 마무리
- 위키 시전 시간 68개 전부 확인(`wiki_cast_times.json` status=confirmed). 미확인 19개는 위키 데이터 템플릿(WebSearch, wiki.leagueoflegends.com 한정)으로 확인했습니다. 사용자 제공 표(confirmed-db) 10개도 위키와 대조해 모두 일치했습니다. 세트 E 출처 충돌(0.25 vs 0.75)은 0.25로 해소됐습니다(0.75는 다른 스킬 블록 값으로 보임). 와일드 리프트(WR) 템플릿 값은 쓰지 않았습니다.
- 확인 과정에서 원작과 다른 동작을 찾아 고쳤습니다(위 표의 9차 메모). 노틸러스 E 시전 시간, 야스오 W 0.013초·이동 가능, 레넥톤 W 0.2초 + 0.528초 잠금, 아리 W 행동 잠금 제거, 닐라 R 선딜·종료 잠금 제거, 요네 E 최초 돌진 뒤 약 3.5초 잠금 → 0.25초와 재시전 0.225초, 모데카이저 W 재시전 0.5초 제한입니다. 수정 후 6개 챔피언(노틸러스·야스오·레넥톤·아리·닐라·요네)을 브라우저에서 다시 측정했습니다.
- 벡스 E 투사체 속도 1300은 위키로 확인해 추정 표시를 없앴습니다.
- 남은 차이:
  - 다리우스 R 시전 후 0.25초 Q/E 금지 - 게임은 0.15초 전체 잠금. 공용 타이밍 표가 "이동 허용 = 시전 취소"만 지원해 그대로 뒀습니다.
  - 모데카이저 E 효과 0.5초 지연 - 위키 요약에서 확인하지 못했습니다.
  - 레넥톤 W 타격 간격 - 위키에 없어 동시 판정합니다.
  - 야스오 E 피해 시점(돌진 시작/도착).
  - 벡스 패시브(파멸과 우울) 미구현 - 재사용 대기시간이 출처마다 다릅니다(템플릿 25/22/19/16, V14.5 패치 22~18).

## 4-3. 영상 비교 칸(8차 추가)
`motion_timing.csv/json` 끝에 `videoMotionPeaksSec`, `videoObservedEffectSec`, `videoComparisonStatus`, `videoAnalysisMethod`를 추가했습니다. 기존 칸 순서는 그대로입니다.
- `videoObservedEffectSec`는 영상에서 **관찰한** 이펙트 출현 시각입니다. 게임의 실제 피해 판정(`gameFirstDamageMs`)과 같은 값으로 취급하지 않습니다.
- 영상 시각은 영상 자체의 0초 기준입니다. 공식 미리보기 영상에는 입력 시점 표식이 없어서, 게임 측정과 직접 빼서 비교하려면 기준점 정렬이 필요합니다. 그래서 신뢰도는 low로 둡니다.
- 현재 68행 전부 `미비교: 영상 미확보`입니다.

## 5. 검증이 필요한 항목
- 공식 영상 프레임 비교 68건 전부(영상 미확보 - 세션 egress 프록시가 wiki.leagueoflegends.com을 허용하지 않음).
- 위키 시전 시간: 9차에서 68건 모두 확인(남은 미확인 없음).
- 피해가 측정되지 않은 스킬 중, 원작에서 피해가 없는 스킬은 플래그에서 뺐습니다(가렌 W, 다리우스 E, 이즈리얼 W 표식 등).
